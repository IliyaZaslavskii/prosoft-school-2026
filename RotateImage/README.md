# RotateImage

## Задача

<Вам дано `n x n` двумерное `matrix` изображение,
поверните его на **90 гр.** (по часовой стрелке).

Вам необходимо повернуть изображение на месте,
что означает, что вам нужно напрямую изменить
входную двумерную матрицу. **НЕ следует** выделять другую
двумерную матрицу и выполнять вращение сразу.>

**Пример 1:**
```
Вход:  matrix = [[1,2,3],[4,5,6],[7,8,9]]
Выход: [[7,4,1],[8,5,2],[9,6,3]]
```

**Пример 2:**
```
Вход:  matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
Выход: [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

**Ограничения:**
- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## Решение

1. Создаем вектор `result`
2. Проходим по всем строкам исходной матрицы
3. Проходим по всем столбцам исходной матрицы
4. Кладем `matrix[i][j]` в `result[j][n - 1 - i]`
6. Копируем `result` обратно в `matrix`.

## Файлы

- `RotateImage/RotateImage.cpp` — исходный код
- `RotateImage.slnx` — solution для Visual Studio

## Как собрать

Открыть RotateImage.slnx в Visual Studio, собрать, запустить.
