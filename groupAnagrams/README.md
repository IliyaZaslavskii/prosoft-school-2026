# groupAnagrams

## Задача

Дан массив строк `strs`. Сгруппируйте анаграммы вместе.
Порядок групп и порядок слов внутри группы — любой.

**Анаграмма** - это слово, полученное перестановкой букв другого
слова, при этом все исходные буквы используются ровно один раз.>

**Пример 1:**
```
Вход:  strs = ["eat","tea","tan","ate","nat","bat"]
Выход: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

**Пример 2:**
```
Вход:  strs = [""]
Выход: [[""]]
```

**Ограничения:**
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `s` состоит из строчных английских букв

## Решение

1. Создаем хеш-таблицу, где:
   - **ключ** — отсортированная по алфавиту версия слова
   - **значение** — список всех слов с таким ключом.
2. Для каждого слова:
   - копируем его,
   - сортируем буквы — получаем ключ,
   - кладем исходное слово в map по этому ключу.
3. Преобразуем значения map в `vector<vector<string>>` и возвращаем.

Анаграммы дают одинаковый ключ.
