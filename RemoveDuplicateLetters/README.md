# RemoveDuplicateLetters

## Задача

<Дана строка `s`. Удалите повторяющиеся буквы так, чтобы каждая буква
встречалась ровно один раз. Результат должен быть в лексикографически
наименьшем порядке среди всех возможных вариантов.>

**Пример 1:**
```
Вход:  s = "bcabc"
Выход: "abc"
```

**Пример 2:**
```
Вход:  s = "cbacdcbc"
Выход: "acdb"
```

**Ограничения:**
- `1 <= s.length <= 10^4`
- `s` состоит из строчных английских букв

## Решение

1. Считаем, сколько раз встречается каждая буква
2. Идем по строке слева направо и храним текущий ответ.
3. Перед добавлением текущей буквы смотрим на верхушку стека:
   - Если там буква больше текущей (например, 'z' > 'a')
   - И эта буква встретится еще раз дальше (счетчик > 0)
   - То удаляем ее со стека  потом добавим в правильном порядке.
4. Если буква уже есть в ответе пропускаем ее.
5. В конце разворачиваем стек.
