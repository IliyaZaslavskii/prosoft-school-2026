# maxSlidingWindow

## Задача

<Вам дан массив целых чисел `nums`. В нем находится скользящее окно размера `k`, которое перемещается от самого левого края массива к самому правому.
Вы можете видеть только `k` чисел, находящихся в окне. При каждом шаге скользящее окно перемещается вправо на одну позицию.
Верните максимальное значение для каждого положения скользящего окна.>

**Пример 1:**
```
Вход:  nums = [1,3,-1,-3,5,3,6,7], k = 3
Выход: [3,3,5,5,6,7]
```

**Пример 2:**
```
Вход:  nums = [1], k = 1
Выход: [1]
```

**Ограничения:**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## Решение

1. Создаем пустой вектор `result` для хранения максимумов каждого окна.
2. Создаемtм двустороннюю очередь, в которой будем хранить индексы элементов массива
3. Проходим по массиву `nums`. Удаляем элементы, вышедшие за границы окна. Удаляем элементы с конца, которые меньше `nums[i]`.
4. Добавляем текущий индекс dq.push_back(i).
4. Возвращаем вектор `result`.
