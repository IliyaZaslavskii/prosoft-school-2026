# SearchInRotatedSortedArray

## Задача

<Дан целочисленный массив nums,
отсортированный по возрастанию и содержащий различные значения.
Перед передачей в вашу функцию массив nums мог быть циклически сдвинут влево на неизвестное
количество позиций `k (1 <= k < nums.length)`. В результате получается массив: `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]`
Индексация начинается с нуля. Например, массив: `[0, 1, 2, 4, 5, 6, 7]` при циклическом сдвиге влево на 3 позиции превращается в
`[4, 5, 6, 7, 0, 1, 2]`: Вам даны массив nums после возможного сдвига и целое число target.
Верните индекс элемента `target`, если он присутствует в массиве nums, или -1, если его нет.
Необходимо написать алгоритм со временем выполнения `O(log n)`.>

**Пример 1:**
```
Вход:  nums = [4,5,6,7,0,1,2], target = 0
Выход: 4
```

**Пример 2:**
```
Вход:  nums = [4,5,6,7,0,1,2], target = 3
Выход: -1
```

**Пример 3:**
```
Вход:  nums = [1], target = 0
Выход: -1
```

**Ограничения:**
- `1 <= nums.length <= 5000`
- `-10^4 <= nums[i] <= 10^4`
- Все значения nums уникальны
- `nums` - это возрастающий массив, который, возможно, вращается
- `-10^4 <= target <= 10^4`

## Решение

1. Определяем, повернут ли массив: если `nums[right] < nums[left]`, значит массив был  сдвинут
2. Разворачиваем массив
3. Бинарным поиском находим индекс переменной `target`
4. если таргета нет, передаем -1.
